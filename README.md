# command-cooldown-mod-ccm-fabric-26.2
Command Cooldown (Ccm) versieht alle Vanilla- und Mod-Befehle mit einem individuellen Cooldown pro Spieler (Standard: 20 Sekunden). Die Zeiten lassen sich flexibel über eine Konfigurationsdatei anpassen oder komplett deaktivieren. Änderungen werden mit ⁠/cooldownconfig reload⁠ sofort und ganz ohne einen Neustart des Servers übernommen.
